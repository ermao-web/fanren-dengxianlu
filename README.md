# fanren-dengxianlu
《凡人登仙录》Demo：LLM 生成卡牌的修仙回合制文字游戏，每回合三选一，从凡人到元婴。Fanren Dengxian Lu Demo: A turn-based text card game about a mortal's path to immortality. Each turn, an LLM generates three opportunity cards—pick one. Rule engine handles numbers, LLM handles narrative. Pure front-end, offline playable.
